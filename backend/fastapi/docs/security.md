# 安全规范

## 身份认证与授权
- 认证确认用户身份，授权确认用户能否执行操作。
- 权限校验放在可复用依赖或 Service 规则中，不能只隐藏前端按钮。
- JWT 校验签名、过期时间、签发方和受众（若适用）。
- 密码采用 Argon2id 或项目安全评审通过的密码哈希方案。
- Token、密码、验证码不得写入普通日志。

## 输入与输出
- 所有外部输入通过 Schema 校验。
- 文件上传校验大小、扩展名、MIME 和文件内容；随机化存储名。
- 防止路径穿越、SSRF、SQL 注入和不安全反序列化。
- 错误响应不包含堆栈、SQL、服务器路径或内部配置。

## Web 安全
- 生产环境强制 HTTPS。
- CORS 只允许明确可信 Origin，不使用生产环境通配符搭配凭据。
- 按部署环境配置 TrustedHost、Cookie Secure / HttpOnly / SameSite。
- 登录、短信、导出、上传等接口增加限流、审计和告警。
- 设置请求体大小、超时和上传限制。

## 配置与密钥
- 密钥使用环境变量或 Secret Manager。
- `.env.example` 只保留变量名和非敏感示例值。
- 定期轮换密钥；泄漏后立即吊销和替换。
