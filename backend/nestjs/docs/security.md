# API 与安全规范

- 所有输入必须验证类型、长度、范围和格式。
- 不信任客户端传入的 userId、tenantId、role 或权限信息。
- 使用统一认证 Guard/Strategy 和角色/权限策略。
- 每次资源读写校验资源归属，防止越权。
- 密码使用成熟安全哈希算法；禁止明文或可逆加密。
- CORS 生产环境仅允许明确来源。
- 登录、验证码、密码重置和高成本接口配置限流。
- 上传限制文件大小、类型和数量；外部 URL 功能评估 SSRF 风险。
- `.env` 不提交 Git，提供无真实密钥的 `.env.example`。
- 生产凭证使用部署平台 Secret；数据库账号遵循最小权限。
- 日志结构化并包含 requestId；过滤 Token、Cookie、密码和个人敏感字段。
- 健康检查区分进程存活与数据库等依赖就绪。
- 生产关闭调试堆栈和敏感错误详情。
