# AI Agent 工程通用规范

## 开工

- 阅读项目入口和任务相关规范，检查现有目录、实现、配置和锁定依赖版本。
- 搜索已有能力，优先复用，避免重复实现、模块和依赖。
- 复杂改动先说明涉及的文件、方案和兼容性影响。按当前任务范围做局部修改。

## 实施

- 保持公共 API 和业务行为兼容。改变公共契约、数据结构、技术栈或依赖主版本前，按项目要求确认并说明迁移影响。
- 将第三方客户端的初始化和生命周期集中在明确的边界。按稳定能力抽象，避免机械复制第三方接口。
- 密钥通过项目配置或密钥管理服务提供。日志和外部错误响应不得暴露凭证、敏感信息或内部堆栈。保留足够的异常上下文。
- 发现存量代码与规范冲突时，在交付中说明，当前任务只修改必要范围。

## 验证与交付

- 按项目已有脚本运行相关静态检查、测试和构建。
- 汇报变更范围、契约与依赖变化、迁移步骤、实际检查结果和剩余风险。无法运行的检查注明原因。
